# XAVIERPOSTERIZE — Poster Store Starter

A responsive static storefront demo built with HTML, CSS and JavaScript.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Before launch
- Product artwork and prices are sample placeholders. Replace them with artwork you own or are licensed to sell, and actual prices.
- Edit `WHATSAPP_NUMBER` and `CONTACT_EMAIL` near the top of `script.js`.
- The cart currently creates a WhatsApp order message. It does **not** collect payment, save orders to a database, or create shipping labels automatically.
- For online card/UPI payments, connect a payment provider through a secure backend or use an ecommerce platform. Do not put secret API keys in browser JavaScript.
- Add your shipping, returns, privacy, and terms policies before accepting real orders.
- Confirm your print paper, actual sizes, shipping charges, taxes and delivery times before publishing.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a new public repository named `xavierposterize`.
3. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
4. Open repository **Settings → Pages**.
5. Under build/deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish and open the URL shown on the Pages settings screen.

GitHub Pages hosts static files; it is not a payment processor or order database. Keep the first launch as a catalog + WhatsApp order flow until you connect a secure checkout solution.
